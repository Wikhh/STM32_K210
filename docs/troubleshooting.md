# 故障排查指南

## 1. K210 端

### `ImportError: cannot import name MIC_ARRAY`

可能原因：

- 当前 MaixPy 固件不包含麦克风阵列接口；
- 固件与开发板型号不匹配；
- 使用的不是该工程面向的 MaixPy API。

处理：

1. 确认开发板和固件版本；
2. 运行最小测试验证 `from Maix import MIC_ARRAY`；
3. 再测试 `mic.init()`、`mic.get_map()` 和 `mic.get_dir()`。

### LCD 有图但串口无输出

1. 检查声源强度是否达到阈值；
2. 查看 MaixPy IDE 终端是否打印“发送角度到STM32”；
3. 用 USB-TTL 单独监听 K210 IO30；
4. 确认终端参数为 9600、8N1。

### 角度抖动或跳变

1. 避免多个强声源同时存在；
2. 降低环境反射和持续噪声；
3. 检查麦克风阵列安装朝向；
4. 重新评估卡尔曼参数 `Q`、`R`；
5. 对 0°/360° 跨界采用圆周角滤波，而不是普通线性滤波。

## 2. 串口通信

### STM32 一直收不到数据

按顺序检查：

1. K210 IO30 是否接 STM32 PA10；
2. 两块板是否共地；
3. 电平是否为 3.3 V TTL；
4. 两端是否都是 9600、8N1；
5. K210 数据是否包含 `@` 和行结束符；
6. STM32 是否正确进入 `USART1_IRQHandler()`；
7. PA9/PA10 是否与其他模块冲突。

### 偶发错误角度

当前协议没有校验。可先用逻辑分析仪捕获：

```text
@xxx.xx\r\n
```

若链路数据正确，再检查：

- 中断优先级和中断占用；
- `packet_ready` 尚未处理时是否收到下一帧；
- 缓冲区是否被其他代码修改；
- 是否需要为共享变量增加更严格的并发保护。

## 3. STM32 与 Keil

### Keil 提示设备或头文件缺失

1. 安装 STM32F1 Device Family Pack；
2. 检查工程目标是否为 STM32F103C8；
3. 检查 Include Paths 是否仍指向仓库内 `Library/inc`、`Startup`、`User`、`Laasckp`；
4. 中文路径导致旧工具异常时，将仓库临时放到纯英文短路径编译。

### 下载成功但程序不运行

1. 检查 BOOT0 是否处于正常 Flash 启动状态；
2. 检查复位、电源和时钟；
3. 使用调试器停在 `main()`；
4. 查看是否频繁进入 HardFault；
5. 检查 TIM2 10 μs 中断是否占用过高。

## 4. 电机与底盘

### 电机完全不转

1. 电机驱动电源是否存在；
2. MCU 与驱动板是否共地；
3. 驱动板 STBY/EN 引脚是否已使能；
4. PA6、PA7、PB0、PB1 是否有电平变化；
5. `received_angle` 是否一直为 0；
6. 软件占空比是否达到电机起转要求。

### 小车转向相反

1. 确认左右电机没有接反；
2. 确认电机在底盘上的镜像安装方向；
3. 单独测试 `CarGo()`、`CarBack()`、`CarLeft()` 和 `CarRight()`；
4. 在 `interface.h` 集中修正方向宏。

### 小车持续旋转

1. OLED 显示角度是否能进入 240°～265°；
2. 麦克风阵列的 0°基准是否与车头方向一致；
3. 目标角 250° 是否适合实际安装方向；
4. K210 是否因噪声持续输出错误方向；
5. 先降低固定旋转占空比，避免过冲。

## 5. 调试建议

建议按以下顺序分层验证：

1. **感知层**：K210 终端能稳定输出合理角度；
2. **通信层**：USB-TTL 能看到标准数据帧；
3. **解析层**：STM32 OLED 能显示对应角度；
4. **执行层**：固定写入测试角度，电机方向正确；
5. **闭环层**：车轮离地完成全链路验证；
6. **实车层**：低速落地测试并记录问题。
